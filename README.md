# 💬 Chat Network (ธีมสีฟ้า · รองรับ Tailscale VPN / LAN / มือถือ)

**ระบบแชทเครือข่ายภายในองค์กรและทีมงาน** พัฒนาด้วย Flask แบบ Single File (`chat_app.py`) พร้อมดีไซน์ธีม **ฟ้าคราม (Sky & Ocean Blue)** ทันสมัย สวยงาม ใช้งานได้จริง รองรับทั้งคอมพิวเตอร์และมือถือผ่าน **Tailscale VPN**, วง **Wi-Fi / LAN** และระบบสแกน **QR Code**

---

## ✨ ฟีเจอร์ใหม่และจุดเด่น

- 🎨 **ธีมสีฟ้าสดใส (Sky & Ocean Blue Theme)**: ดีไซน์ใหม่ Modern Glassmorphism สบายตา พร้อมฟอนต์ IBM Plex Sans Thai
- 🌐 **รองรับ Tailscale VPN เต็มรูปแบบ**: ตรวจจับ IP ของ Tailscale (`100.x.x.x`) อัตโนมัติ เชื่อมต่อได้ทุกที่ทั่วโลกเสมือนอยู่ในวง LAN เดียวกัน
- 📱 **รองรับการเชื่อมต่อจากมือถือ & สแกน QR Code**: หน้าเว็บมีปุ่มเปิด QR Code ให้เพื่อนร่วมทีมเปิดกล้องมือถือสแกนเข้าแชทได้ทันที โดยไม่ต้องพิมพ์ URL เอง
- 🔒 **กำหนดห้องแบบ "มีรหัสผ่าน" หรือ "ไม่ต้องใส่รหัส"**:
  - **ห้องสาธารณะ (ไม่ต้องใส่รหัส)**: สมาชิกในวงเครือข่ายสามารถกดเข้าร่วมได้ทันทีจากหน้ารายการห้อง
  - **ห้องส่วนตัว (มีรหัสผ่าน)**: ผู้สร้างห้องสามารถตั้งรหัสผ่านสำหรับคนที่มีสิทธิ์เข้าเท่านั้น
- 🖼️ **ส่งรูปภาพ & ถ่ายภาพจากมือถือ**: สามารถแนบรูปถ่ายจากมือถือ หรือกด `Ctrl + V` วางรูปจากคลิปบอร์ดในคอมพิวเตอร์ได้ทันที พร้อมระบบย่อรูปอัตโนมัติเพื่อความเร็วสูง
- 🔔 **เสียงแจ้งเตือนข้อความใหม่ (Web Audio Chime)**: มีเสียงเตือนนุ่มนวลเมื่อมีข้อความเข้า และสามารถกดเปิด/ปิดเสียงได้
- 🟢 **สถานะออนไลน์แบบ Real-time**: แสดงจำนวนและรายชื่อผู้ที่กำลังออนไลน์อยู่ในห้อง
- 📋 **คัดลอกรหัสห้อง / ลิงก์เชิญ**: คัดลอกรหัส 4 หลักหรือส่งลิงก์ห้องให้เพื่อนได้สะดวก
- 💾 **ระบบฐานข้อมูล SQLite อัตโนมัติ (`chat.db`)**: ไม่ต้องตั้งค่า Database เพิ่มเติม

## 🚀 วิธีการติดตั้งและรันโปรแกรม

### 1. ติดตั้ง Dependencies

```bash
pip install -r requirements.txt
```

### 2. รันโปรแกรม

```bash
python chat_app.py
```

เมื่อรันสำเร็จ โปรแกรมจะแสดงที่อยู่ IP สำหรับเชื่อมต่อดังนี้:
```text
============================================================
 🚀 Chat Network กำลังทำงานบนเซิร์ฟเวอร์...
 🌐 สำหรับเครื่องนี้: http://127.0.0.1:5000
 📱 สำหรับมือถือ/เครื่องอื่น [Tailscale VPN]: http://100.112.249.105:5000
 📱 สำหรับมือถือ/เครื่องอื่น [Wi-Fi / LAN]: http://192.168.2.104:5000
============================================================
```

## 📱 วิธีเชื่อมต่อผ่าน Tailscale และมือถือ

### 🌐 วิธีที่ 1: เชื่อมต่อผ่าน Tailscale VPN (เชื่อมต่อได้จากทุกที่ทั่วโลก)
1. ติดตั้งแอป **Tailscale** บนเครื่องคอมพิวเตอร์และบนมือถือ (มีทั้ง iOS และ Android)
2. ล็อกอินบัญชี Tailscale บัญชีเดียวกัน (หรือแชร์โหนด Tailnet เข้าด้วยกัน)
3. เปิดเบราว์เซอร์แล้วพิมพ์: `http://<IP Tailscale ของเครื่องโฮสต์>:5000` (เช่น `http://100.112.249.105:5000`)
4. หรือ **สแกน QR Code** บนหน้าจอคอมพิวเตอร์ด้วยมือถือที่เปิด Tailscale อยู่

### 📶 วิธีที่ 2: เชื่อมต่อในวง Wi-Fi / LAN เดียวกัน (ไม่ต้องใช้เน็ตนอก)
1. ให้มือถือหรือเครื่องอื่นต่อ Wi-Fi วงเดียวกับเครื่องโฮสต์
2. เปิดเบราว์เซอร์แล้วพิมพ์: `http://192.168.2.104:5000` หรือสแกน QR Code ได้ทันที

## 🔒 การจัดการห้องแชท (รหัสผ่านห้อง)

1. **สร้างห้องสาธารณะ**: ไม่ต้องติ๊ก "การป้องกันด้วยรหัสผ่าน" ทุกคนจะสามารถมองเห็นห้องและกดเข้าได้ทันที
2. **สร้างห้องส่วนตัว**: ติ๊กเปิด "การป้องกันด้วยรหัสผ่าน" แล้วกรอกรหัสผ่านที่ต้องการ เมื่อผู้อื่นจะเข้าห้องจะต้องกรอกรหัสผ่านก่อนเข้าสู่ห้องสนทนา
3. **การลบห้อง**: ผู้สร้างห้องจะมีปุ่ม "🗑️ ปิดและลบห้องนี้" อยู่ที่แถบด้านข้าง

## ⚙️ การตั้งค่า Environment Variables (ถ้าต้องการ)

| ตัวแปร | ค่าเริ่มต้น | คำอธิบาย |
|---|---|---|
| `PORT` | `5000` | พอร์ตการทำงานของเซิร์ฟเวอร์ |
| `SECRET_KEY` | `chat-network-tailscale-blue-2026` | คีย์สำหรับความปลอดภัยของ Session |
| `CHAT_DB` | `chat.db` | ที่อยู่ไฟล์ฐานข้อมูล SQLite |
